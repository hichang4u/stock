# C2 — 당일 공시 + 14:50~15:20 시장 대비 강세 종가 매수 가설 (등록 초안)

> 작성: 2026-11-25 (격리 브랜치 `hichang4u/close-buy-rules-20261125`)
> 상태: **등록 초안: 규칙과 임계값은 고정했고 사용자 승인 전이다.** 수집기는 없고 표본은 0이다.
> 운영 변경은 없다. 주문 코드, 설정, 예약 작업, 브로커 API, 인증은 건드리지 않았다.
> 선행: [C1 (닫힘)](2026-09-21-c1-overnight-close-hypothesis.md) §7·§8 ·
> [H1 §6 닫힌 축](2026-09-11-h1-gap-selection-hypothesis.md) ·

이 문서는 C2의 손익을 한 건도 보지 않은 상태에서 규칙·상수·판정 기준을 고정한다.
등록 전에 본 데이터는 다음 세 가지뿐이다.

- C1의 기록(§7)
- 저장 자료가 무엇을 담고 있는지에 대한 점검(§8)
- 11/23 분봉 6종목의 가격 구간(§8.3). 손익 판정에는 쓰지 않는다.

승인 전에는 사용자가 조건을 고칠 수 있다. 그러려면 표본이 아직 0이어야 하고, 무엇을 왜
고쳤는지 §11에 남긴다. 첫 표본이 기록된 뒤에는 아무것도 바꾸지 않는다. 바꾸고 싶으면 C3로 새로
등록한다.

## 0. 이 문서가 하는 것과 하지 않는 것

**하는 것:**
- 처음 시험할 규칙 하나를 재현할 수 있는 형태로 고정한다(§3, 부록 A의 순수 함수).
- 판정에 필요한 최소 관찰 증거를 정한다(§5).
- 현재 저장된 자료만으로 입력을 시점 일치로 복구할 수 있는지 실제로 점검한다(§8).
- 로컬 합성 사례로 절차를 점검한다(§9).

**하지 않는 것:**
- C1 재활성화. 이 작업에서 `StockBot_OvernightScreen`과 `StockBot_OvernightScreen1520`의
  비활성 상태를 건드리지 않았고, 다시 켜지도 않는다.
- 수집기 구현.
- 주문 경로 연결.
- 운영 트리 쓰기. 운영 트리는 읽기만 했다.

## 1. C1과 무엇이 다른가 (닫힌 축 확인)

| | C1 (2026-11-19 닫힘) | C2 (이 문서) |
|---|---|---|
| 모집단 | 시장별 거래량 상위 30 | 그날 **KIND에 시각과 함께 공개된 화이트리스트 공시**가 있는 종목 |
| 선정 근거 | 등락률 3~25%, 종가 위치 ≥ 0.8, 거래대금 20일 평균 2배 | 재료가 있고, **14:50~15:20에 소속 시장 지수보다 강했다** |
| 순위 | 거래대금 배수 | 시장 대비 초과 상승폭(RS) |
| 신호 시각 | 15:32 (종가 확정 후, 실주문 불가) | **15:20:00** (종가 단일가 전, 실주문 가능한 시각) |
| 청산 | D+1 트랙 A F4 규칙 | **D+1 시가 단일가** |
| 하루 건수 | 랭크 1 | **최대 1종목, 무거래 허용** |

- **C1 §8:** C1은 "다른 규칙을 C2로 새로 등록하고 등록 뒤 표본으로만 판정"하라고 했다. 이 문서가
  그 C2다. C1이 남긴 15:20 병행 기록(`data/overnight/candidates_1520/`, 10-14~11-18)은 닫힌 축의
  자료이고 14:50 값도 없다. 그래서 C2의 판정에도 소급 시험에도 쓰지 않는다(§8.1).
- **H1 §6:** "진입 시각 09:01~13:00 종가 진입"은 갭상승 종목의 장중 진입 축이다. C2는 장 마감
  진입이라 그 축에 닿지 않는다. 신고가 돌파(H5)와 3양봉, VWAP 축도 쓰지 않는다.
- **H2:** H2는 등록돼 있고 열린 가설이다. 직전 거래일 공시로 트랙 A의 갭 종목을 거른다. C2는 당일
  공시와 다른 트랙을 쓰고, H2의 화이트리스트·창·판정을 바꾸지 않는다. 두 가설의 화이트리스트는 서로
  다르다(§3.2). H2의 5% 대량보유 문제는 C2 목록에서 처음부터 뺐다.
- **C1에서 이미 본 것(청산 선택에 대한 공개):** 청산을 D+1 시가로 정하기 전에 C1 랭크 1의 시가 갭을
  보았다(11-19 기록: 평균 −0.54%, 중앙값 −0.11%). 이 값은 음수라 시가 청산을 고를 근거가 되지
  않는다. 시가 청산을 고른 이유는 세 가지다.
  - 외부 추천 검토서(11/23)의 비교 정의(종가 → 익일 시가)와 같은 자로 잴 수 있다.
  - 입력이 일봉 두 값뿐이라 재현성이 가장 높다.
  - 장중 재생의 편향이 없다. C1 11-02 점검의 틱 대 분봉 비교에서 분봉 재생이 트레일 청산을 좋게
    잡는 쪽으로 기울었다.

## 2. 가설

> 매 정규 거래일 D-0 **15:20:00**에 §3 규칙으로 **최대 1종목**을 고른다. 그 종목을
> **D-0 종가 단일가**에 사서 **D+1 시가 단일가**에 팔면, 판정 비용(왕복 0.25%p)을 뺀 거래당
> 기대수익이 0보다 크다.

메커니즘(한 문장): 당일 공개된 새 재료에 시장이 장 막판까지 지수보다 강하게 반응한 종목은, 그
반응이 마감까지 다 반영되지 않아 다음 날 시가에서 이어진다.

재료는 "무엇이 새로 알려졌나"를 보고, RS는 "시장이 그것을 호재로 읽었나"를 본다. 재료의 방향
(호재인지 악재인지)은 사람이 판단하지 않는다. RS가 그 판단을 대신한다. 그래서 실적 공시처럼 방향이
정해지지 않은 공시도 화이트리스트에 둔다.

## 3. 규칙 (고정)

### 3.1 거래일, 신호 시각, 예외장

- **신호 시각은 D-0 15:20:00 KST다.** 모든 입력은 이 시각 이전에 공개됐거나 체결된 값이어야
  한다. 종가 단일가(15:20~15:30)에 주문을 낼 수 있는 마지막 정보 시점이다.
- **D-0 예외장이면 그날 전체를 건너뛴다(`SKIP_SPECIAL_SESSION`, 표본 밖).**
  - 정규장(09:00~15:30)이 아닌 날: `src/market_calendar.py`의 `LATE_OPEN_DAYS`(수능일, 새해 첫
    거래일 같은 10:00 개장일), 그리고 KRX가 공지한 단축·지연 운영일.
  - 14:50~15:20에 시장 전체 서킷브레이커가 걸린 날(`SKIP_MARKET_HALT`). 사이드카는 기록만 하고
    건너뛰지 않는다.
  - 판단은 KRX 공지가 기준이고, 목록은 해마다 사람이 더한다. 메모리 "KRX 10시 개장일"과 같은
    절차다.
- **D+1이 10:00 개장일이면 그날 시가 단일가(10:00)에 청산한다.** 플래그 `D1_LATE_OPEN`을 남기고
  표본에 넣는다.
- **거래일 판정에는 KRX 거래일 달력을 쓴다.** `data/overnight/calendar.json`은 C1 스크리닝이 멈춘
  11-19에서 끊겼다(§8.1). 그래서 C2는 그것에 기대지 않고 수집기가 따로 달력을 갖는다.

### 3.2 재료: 당일 공개된, 검증 가능한 신규 공시와 회사 발표

**소스는 KIND(한국거래소 기업공시채널) 공시 목록 하나다.** KIND는 공시마다 공시번호와 분 단위
공개 시각을 준다. DART는 원문 확인용 링크(`rcept_no`)로만 쓴다. DART 목록 API는 접수 **일자**만
주고 시각을 주지 않는다(H2 §2.1). 그래서 15:20 경계를 그을 수 없다.

**회사 발표**는 거래소 공시(공정공시 포함)로 제출된 것만 인정한다. 보도자료, 홈페이지 게시물,
기사, IR 자료는 첫 시험에서 뺀다. 공개 시각을 바꿀 수 없는 기록으로 남기지 못하고, 같은 입력을
나중에 다시 만들 수 없기 때문이다.

공시 하나가 재료로 인정되려면 아래 조건을 모두 만족해야 한다. 조건마다 탈락 사유 코드가 있다.

| 조건 | 정의 | 탈락 사유 |
|---|---|---|
| 검증 가능 | 소스가 KIND이고 공시번호가 있다 | `SOURCE_UNVERIFIABLE` |
| 시각 있음 | 공개 시각이 있다 | `NO_TIMESTAMP` |
| 당일 | 공개 일자가 D-0이다(00:00 이후). D-1 장 마감 후 공시는 당일이 아니다 | `NOT_SAME_DAY` |
| 신호 전 | 공개 시각 ≤ 15:20:00 | `AFTER_SIGNAL` |
| 신규 | 보고서명이 정정 접두어로 시작하지 않는다 | `AMENDMENT` |
| 유형 | 보고서명이 화이트리스트에 든다 | `NOT_WHITELISTED` |

- **시각 경계:** KIND 시각은 분 단위다. 그래서 `HH:MM`은 **`HH:MM:59`로 저장한다**(보수적 상한).
  15:20 공시는 15:20:59가 되어 탈락하고, 15:19 공시까지만 인정된다.
- **정정 접두어:** `[기재정정]`, `[첨부정정]`, `[첨부추가]`, `[변경등록]`, `[정정]`.
- **화이트리스트:** 보고서명과 키워드의 공백을 모두 지운 뒤 부분 문자열로 맞춘다. 키워드는
  부록 A의 `WHITELIST`와 같다.

```
단일판매ㆍ공급계약체결   영업(잠정)실적        매출액또는손익구조
자기주식취득결정          자기주식취득신탁계약체결결정   주식소각결정
무상증자결정              유형자산취득결정       타법인주식및출자증권취득결정
신규시설투자              특허권취득            기술도입ㆍ이전ㆍ제휴계약체결   기술이전계약
투자판단관련주요경영사항
```

**목록에서 뺀 것과 이유:**
- 대량보유와 임원 소유 보고: 지분 신고이고 새 사업 정보가 아니다. H2에서 문제가 된 부분이다.
- 유상증자, CB, BW, EB: 희석 공시다.
- 합병, 분할, 감자: 기준가가 바뀌는 기업 행위라 시가 손익이 오염된다.
- 조회공시 답변, 정기보고서, 주주총회, IR 개최 안내, 배당: 정기·절차 공시다.

같은 날 한 종목에 희석 공시가 함께 나와도 별도로 빼지 않는다. 방향은 RS가 거른다.

### 3.3 가격과 거래대금 정의

**소스는 1분봉이다.** KIS 일별분봉 `FHKST03010230` 또는 같은 정의의 소스를 쓴다. 봉 라벨은
**분의 시작**이다. 라벨 `144900`은 14:49:00~14:49:59의 체결을 담는다. 이 정의는 §8.2에서 틱으로
실측해 확인했다.

| 값 | 정의 |
|---|---|
| `p1450` | 라벨 ≤ `144900`인 마지막 봉의 종가 (14:50:00 직전 마지막 체결가) |
| `p1520` | 라벨 ≤ `151900`인 마지막 봉의 종가 (15:20:00 직전 마지막 체결가) |
| `r_stock` | `p1520 / p1450 − 1` |
| `r_index` | 소속 시장 지수(코스피 종목은 KOSPI, 코스닥 종목은 KOSDAQ)의 같은 정의 값 |
| **`RS`** | **`r_stock − r_index`** (%p) |
| `window_value` | 라벨 `145000` ~ `151900` 봉(30개)의 Σ(거래량 × 봉 종가) |
| `day_value` | 라벨 `090000` ~ `151900` 봉의 Σ(거래량 × 봉 종가) |
| `prev_close` | D-1 종가 (일봉) |
| `upper_limit` | D-0 상한가 (소스의 상한가 필드. 없으면 D-0 기준가와 KRX 호가단위 규칙으로 계산) |
| `close` | **D-0 종가는 일봉에서 받는다.** 분봉의 `153000` 봉은 절반 넘게 없다(§8.4) |
| `close_auction_volume` | D-0 `153000` 봉의 거래량. 없으면 일봉 거래량 − Σ(`090000`~`151900` 봉 거래량) |
| `d1_open` | D+1 시가 (일봉) |
| `d1_base` | D+1 기준가. 일봉에서 `D+1 종가 − D+1 전일대비`로 구한다 |

- **봉이 빠진 경우:** 체결이 없는 분은 봉이 없다. 그 분의 가격은 직전 봉 종가로 잇는다.
  **14:50~15:20 사이 봉이 하나도 없으면 `DATA_MISSING`이다.**
- **봉 거래대금 필드:** 소스가 주더라도 쓰지 않는다. 재현성을 위해 위의 v × c 정의를 고정한다.

### 3.4 필터 (재료 있는 종목마다, 이 순서로, 첫 탈락 사유를 기록)

| 순서 | 조건 | 탈락 사유 |
|---|---|---|
| 1 | 위 입력이 모두 있다. 지수 `p1450`과 `p1520`도 포함한다 | `DATA_MISSING` (그날 `degraded=true`) |
| 2 | 코스피 또는 코스닥 **보통주**. ETF, ETN, ELW, 스팩, 리츠, 인프라펀드, 우선주, 코넥스는 아니다 | `NOT_COMMON_KOSPI_KOSDAQ` |
| 3 | 시장조치 대상이 아니다: 관리종목, 투자주의환기, 투자경고·위험, 단기과열, 거래정지(D-0 중 언제든), 정리매매 | `FLAGGED` |
| 4 | 상장 후 20거래일 이상 | `NEW_LISTING` |
| 5 | `p1520 ≥ 1,000원` | `PRICE` |
| 6 | **유동성:** `day_value ≥ 50억원` 그리고 `window_value ≥ 5억원` | `LIQUIDITY` |
| 7 | `p1520 < upper_limit` (15:20에 상한가면 매수 대기열이라 체결을 가정할 수 없다) | `UPPER_LIMIT_1520` |
| 8 | `p1520 > prev_close` (당일 상승 중) | `NOT_UP_ON_DAY` |
| 9 | **`RS > 0`** | `RS_NOT_POSITIVE` |

**시장조치 플래그:** 소스는 KIND 시장조치 또는 KIS 현재가의 상태 필드다. 플래그 소스가 그날
없으면 빼지 않는다. 대신 `flags_unknown=true`를 기록한다. C1 §2.2와 같은 처리다.

**임계값 근거:** 임계값은 자연 경계(0, 상한가, 1,000원)와 어림수(50억, 5억, 20거래일)로만
정했다. 어느 것도 데이터에 맞추지 않았다. 50억은 C1 하한(10억)의 5배로, 오버나이트로 1종목에
집중하는 만큼 높였다. 5억은 50억의 1/10이다.

**VI:** 14:50 또는 15:20에 VI 단일가가 진행 중이면 마지막 체결가가 멈춰 있다. 그래도 빼지 않고
`vi_active`로 기록만 한다(§6 부 지표). 소스가 VI 상태를 주지 않으면 `vi_unknown`이다.

### 3.5 순위, 동률, 1종목, 무거래

- **순위:** `RS` 내림차순. 동률이면 `window_value` 내림차순. 그래도 같으면 종목코드 오름차순.
  셋째 기준은 결정을 하나로 만들기 위한 것이고 의미는 없다.
- **랭크 1만 매수한다.** 상위 5개는 기록만 한다.
- **무거래:** 하루 0건도 정상 결과다.
  - `NO_TRADE_NO_CATALYST`: 재료가 하나도 없는 날
  - `NO_TRADE_NO_PASS`: 재료는 있으나 필터를 통과한 종목이 없는 날
- **무거래일은 손익 0으로 표본에 넣지 않는다.** 따로 센다. 무거래일 비율도 결과의 일부다.

### 3.6 진입, 청산, 체결과 미체결 (그림자 가정)

**가정 주문 금액 N은 1,000만원이다.** 체결 판정에만 쓰는 값이고 실제 주문은 없다.

**진입: D-0 종가 단일가에서 `close` 가격으로 체결을 가정한다.** 가정은 아래 둘을 모두 만족할 때만이다.

1. `close < upper_limit`
2. 종가 단일가 체결대금(`close_auction_volume × close`) ≥ 20 × N. 가정 주문이 단일가 체결대금의
   5% 이하라는 뜻이다.

둘 중 하나라도 어기면 **`UNFILLED`(미체결)**이다.
- 그날은 무거래가 되고 **차순위로 대체하지 않는다.** 15:20의 결정은 하나다.
- 부분 체결은 모델링하지 않는다.

**청산: D+1 시가 단일가(`d1_open`)에 전량 체결을 가정한다.**
- **D+1 시가가 하한가면** 체결을 가정하되 `D1_LIMIT_DOWN_OPEN`을 남긴다. 실제로는 체결되지 않을 수
  있다.
- **D+1에 거래정지면** 재개 후 첫 시가 단일가에 청산한다(`HALT_EXIT`, 보유일 수 기록). 표본에
  넣는다. 실제로 감당할 위험이기 때문이다.
- **기준가 조정:** `d1_base ≠ close`(권리락, 배당락, 분할 등)이면 `EXCLUDED_BASE_ADJUSTED`로 주
  표본에서 빼고 따로 센다. C1의 `SUSPECT_CORPORATE_ACTION`과 같은 취지이고, 기준가를 직접 보므로
  30% 근사가 필요 없다.

### 3.7 거래 비용

| 항목 | 값 | 비고 |
|---|---|---|
| **판정 비용 (왕복)** | **0.25%p** | 프로젝트 연구 상수 0.18%p(`src/perf_costs.py`)보다 보수적으로 잡았다. 매도 제세금과 양방향 수수료를 덮는 수준이다 |
| 단일가 슬리피지 | 0 | 진입과 청산이 모두 단일가 체결이고, 가정 주문이 체결대금의 5% 이하다 |
| 민감도 격자 (기록만) | 비용 0.18 / 0.25 / 0.35%p × 슬리피지 0 / 0.10 / 0.20%p | 0.18 칸은 C1·트랙 A와 같은 자로 비교할 때 쓴다 |

- **손익 계산:** `gross = d1_open / close − 1`, `net = gross − 0.25%p`. **판정은 `net`으로 한다.**
- **실제 요율:** 증권거래세율과 증권사 수수료율은 E3 판정 전에 출처(법령 조문, 증권사 요율표)와
  함께 이 문서 §10에 적는다. 확인된 실제 왕복 비용이 0.25%p를 넘으면 그 값으로 `net`을 다시 낸
  열을 함께 보고한다. 판정 기준을 바꾸는 것은 아니고, 보고를 하나 더하는 것이다.

## 4. 기록 형식

하루에 한 파일을 남긴다: `data/c2/<D-0>.jsonl`. 경로는 수집기 설계 때 확정한다. 내용은 다음과 같다.

- **재료 행:** 공시마다 한 줄. 공시번호, 원문 시각, 저장한 `published_at`, 보고서명, 판정 사유.
- **종목 행:** 재료 종목마다 한 줄. §3.3의 모든 원시 값, 탈락 사유, `RS`.
- **결정 행:** 상태, 랭크 1~5, `degraded`, `flags_unknown`, `recorded_at`.
- **정산 행:** D+1에 같은 파일 끝에 덧붙인다. `SETTLED`, `UNFILLED`, `EXCLUDED_BASE_ADJUSTED` 또는
  `PENDING_*` 중 하나와 비용 격자.
- **외부 추천 행:** 있는 날만. 종목, 발송 시각, 원문 위치, 접근 등급.

**파일이 없는 날의 해석:**
- 파일 없음 + 예외장 아님 = `SCREEN_FAILED`
- 결정 행 없음 = 중간에 죽은 실행

**원시 값 보존:** 원시 값을 남겨서, 나중에 다른 규칙(C3 등)으로 다시 라벨링할 수 있게 한다.
다만 그 결과는 C2 판정에 쓰지 않는다.

## 5. 최소 관찰 증거와 판정 (고정)

### 5.1 표본 자격 — "결과 보기 전 기록"

주 표본이 되는 날은 아래 셋을 모두 만족하는 날뿐이다.

1. D-0가 사용자 승인일 이후다.
2. 결정 행의 `recorded_at`이 **D+1 08:30 이전**이다. 결과(시가)가 정해지기 전에 결정을 기록했다는
   보장이다.
3. 그날의 입력이 §3.3 정의대로 채워졌다.

D+1 08:30 이후에 사후 재구성한 날은 `LATE_RECORDED`로 따로 센다. 입력이 바뀌지 않는 과거 사실이더라도
판정에는 쓰지 않는다. 승인 전 날짜를 소급 재구성한 결과도 체로만 쓴다(H1 §6과 같은 취급).

### 5.2 증거 단계

**1거래일은 어떤 단계에서도 다거래일 검증으로 세지 않는다.**

| 단계 | 증거 | 통과 조건 | 뜻 |
|---|---|---|---|
| **E0 절차** | 합성 사례 (§9) | 8사례 기대값 일치 | 규칙 구현이 문서와 같다. **완료 (2026-11-25)** |
| **E1 입력 복구** | 실제 거래일 1일 | §3.8 입력 네 묶음(공시 시각, 종목 분봉, 지수 분봉, 일봉과 플래그)을 모두 시점 일치로 채움. 분봉 `151900` 종가와 15:20 시점 별도 스냅샷이 있으면 대조함 | 수집이 **가능하다**는 것만 뜻한다. 성과도 안정성도 뜻하지 않는다 |
| **E2 수집 안정성** | 연속 20거래일 | `SCREEN_FAILED + degraded + LATE_RECORDED ≤ 2일`(10%). 무거래일 비율과 `UNFILLED` 비율 기록 | 표본을 셀 수 있다. 손익은 보지 않는다 |
| **E3 판정** | `SETTLED` **n ≥ 50** | 아래 세 조건 모두 | 그림자 통과. PAPER 실주문은 별도 설계 |

**E3 통과 조건** (C1 §4.1과 같은 형식):
1. `net` 평균 > 0
2. bootstrap(10,000회) 95% 신뢰구간 하한 > 0
3. 상위 수익 2건을 뺀 평균 > 0

**조기 중단:** **n = 30에서 한 번만** 본다. `net` 평균 < −1.0% 또는 누적 합산 최대 낙폭 < −15%p이면
축을 닫는다. 값은 C1과 같고 데이터에 맞춘 값이 아니다. 계산은 첫 30건으로 고정한다.

**기한:** E2 시작 후 250거래일 안에 n = 50을 채우지 못하면 "표본 부족"으로 판정 없이 닫는다.
규칙이 너무 좁다는 결과로 기록한다.

**실행 가능성 경고(판정과 별개):** `UNFILLED`가 랭크 1 결정의 20%를 넘으면 규칙을 실행할 수 없다는
경고를 결과에 남긴다. 실패일이 20%를 넘으면 통계보다 수집기를 먼저 고친다. C1 §4.3과 같다.

### 5.3 재평가

- 매월 말에 수치를 §10에 붙인다. 판정은 n ≥ 50에서만 한다.
- 규칙, 임계값, 판정식은 바꾸지 않는다.

## 6. 부 지표 (기록만, 판정에 쓰지 않음)

- **외부 추천 대비 비교.** 외부 추천이 온 날, 각 추천 종목을 C2와 **같은 식**(D-0 종가 → D+1 시가,
  같은 비용)으로 계산한다.
  - 접근 등급: 발송 시각 ≤ 15:20:00이면 `SAME_TIME`, 15:20~15:30이면 `IN_AUCTION`(종가 단일가
    주문은 가능), 15:30 이후면 `AFTER_CLOSE`, 시각을 확인할 수 없으면 `UNVERIFIED`.
  - **접근 가능(`SAME_TIME`, `IN_AUCTION`) 추천만 비교에 쓴다.** 나머지는 가상 수익률로만 남긴다.
    11/23 검토서 3항과 같은 원칙이다.
  - 보고하는 것:
    - 같은 날 C2 `SETTLED`와 외부 추천 동일가중 평균의 차이(쌍 단위 평균과 건수)
    - C2 무거래일의 외부 추천 성과. 무거래가 기회를 놓쳤는지, 손실을 피했는지 본다.
  - 외부 추천 종목이 C2 재료 종목에 들었는지, 들었다면 어느 사유로 탈락했는지도 기록한다.
- **지수 초과:** `gross − (지수 D+1 시가 / 지수 D-0 종가 − 1)`. 시장 전체 갭과 구분하기 위해서다.
- **15:20 → 종가 변화:** `close / p1520 − 1`. 신호 이후 마감 단일가에서 강세가 유지됐는지 본다.
  C1 §6(a)의 15:20 판 진입가 차이(평균 −0.20%)와 같은 축이다.
- **기타:** 랭크 2~5 평균, 공시 유형별 평균, `vi_active` 및 `flags_unknown` 날짜의 성과, 비용
  민감도 격자, 트랙 A와 같은 날 상관.

## 7. 수집기 요구사항 (이 문서 범위 밖, 승인 뒤 별도 설계)

C2를 실제로 관찰하려면 수집기가 필요하다. 이 작업에서는 만들지 않았다. 요구사항만 적는다.

- **운영 매매와 분리:**
  - `main.py`, `src/modules`, 주문 경로, 전략 지문 대상 파일과 환경변수를 건드리지 않는다.
  - 운영 프로세스와 상태를 공유하지 않는다.
  - 실행 시각은 15:20 직후부터 다음 날 08:30 전까지로 한다. C1처럼 `scripts/`와 별도 데이터
    폴더 안에서 끝낸다.
- **KIS 호출 제약:**
  - 앱키당 WS 세션은 1개다. 분봉과 일봉은 REST로만 받는다.
  - 트랙 A 진입 창(09:00~09:11)에는 호출하지 않는다.
  - 운영과 같은 앱키를 쓰므로 호출 예산 상한을 둔다.
- **지수 분봉:** 과거 일자 제공 여부는 수집기 설계의 첫 확인 항목이다. 당일만 준다면 수집기는 반드시
  당일 15:20 이후 장 마감 전후에 돌아야 한다.
- **KIND 수집:** 화면 또는 공개 목록을 읽기만 한다. 원문 응답을 그대로 저장해 공시 시각을 다시
  확인할 수 있게 한다.

## 부록 A. 규칙 구현 (순수 함수, §9에서 실행한 코드와 동일)

```python
"""C2 규칙 — 순수 함수 구현(주문·네트워크·파일 쓰기 없음).

입력은 하루치 dict 하나이고 출력은 결정 dict 하나다. 시각 일치 조건은 입력에 담긴
타임스탬프로만 판단한다(실행 시각을 보지 않는다).
"""
from __future__ import annotations

SIGNAL_HHMMSS = "15:20:00"
WINDOW_START = "14:50:00"
MIN_PRICE = 1_000
MIN_DAY_VALUE = 5_000_000_000        # 09:00~15:19 봉 Σ(거래량×종가) ≥ 50억원
MIN_WINDOW_VALUE = 500_000_000       # 14:50~15:19 봉 Σ(거래량×종가) ≥ 5억원
MIN_LISTED_SESSIONS = 20
NOTIONAL = 10_000_000                # 가정 주문 금액 1,000만원
MAX_AUCTION_SHARE = 0.05             # 가정 주문 ≤ 종가 단일가 체결대금의 5%
COST_PCT = 0.25                      # 판정 비용(왕복, %p)
COST_GRID = (0.18, 0.25, 0.35)
SLIP_GRID = (0.0, 0.10, 0.20)

WHITELIST = (
    "단일판매ㆍ공급계약체결", "단일판매·공급계약체결", "단일판매공급계약체결",
    "영업(잠정)실적", "매출액또는손익구조",
    "자기주식취득결정", "자기주식취득신탁계약체결결정", "주식소각결정",
    "무상증자결정",
    "유형자산취득결정", "타법인주식및출자증권취득결정", "신규시설투자",
    "특허권취득", "기술도입ㆍ이전ㆍ제휴계약체결", "기술이전계약",
    "투자판단관련주요경영사항",
)
AMEND_PREFIXES = ("[기재정정]", "[첨부정정]", "[첨부추가]", "[변경등록]", "[정정]")
EXCLUDED_FLAGS = {"ADMIN", "CAUTION_ENV", "WARNING", "RISK", "OVERHEAT", "HALTED", "LIQUIDATION"}
INDEX_OF = {"KOSPI": "KOSPI", "KOSDAQ": "KOSDAQ"}


def _norm(title: str) -> str:
    return title.replace(" ", "")


def eligible_disclosure(d: dict, date: str) -> str | None:
    """None이면 통과, 아니면 탈락 사유."""
    if d.get("source") != "KIND" or not d.get("id"):
        return "SOURCE_UNVERIFIABLE"
    ts = d.get("published_at") or ""
    if len(ts) < 19:
        return "NO_TIMESTAMP"
    if ts[:10].replace("-", "") != date:
        return "NOT_SAME_DAY"
    if ts[11:19] > SIGNAL_HHMMSS:
        return "AFTER_SIGNAL"
    title = d.get("title", "")
    if title.startswith(AMEND_PREFIXES):
        return "AMENDMENT"
    t = _norm(title)
    if not any(_norm(k) in t for k in WHITELIST):
        return "NOT_WHITELISTED"
    return None


def _ret(a: float, b: float) -> float:
    return (b / a - 1.0) * 100.0


def screen(day: dict) -> dict:
    date = day["date"]
    out: dict = {"date": date, "status": None, "pick": None, "ranked": [], "rejected": {},
                 "disclosures": {}, "degraded": False}
    if day.get("session") != "REGULAR":
        out["status"] = "SKIP_SPECIAL_SESSION"
        return out
    idx = day.get("index", {})
    cands: dict[str, list[str]] = {}
    for d in day.get("disclosures", []):
        why = eligible_disclosure(d, date)
        out["disclosures"][d.get("id") or d.get("title")] = why or "OK"
        if why is None:
            cands.setdefault(d["ticker"], []).append(d["id"])
    if not cands:
        out["status"] = "NO_TRADE_NO_CATALYST"
        return out
    ok = []
    for tk in sorted(cands):
        s = day.get("stocks", {}).get(tk)
        why = _filter(s, idx)
        if why == "DATA_MISSING":
            out["degraded"] = True
        if why:
            out["rejected"][tk] = why
            continue
        ix = idx[INDEX_OF[s["market"]]]
        rs = _ret(s["p1450"], s["p1520"]) - _ret(ix["p1450"], ix["p1520"])
        ok.append({"ticker": tk, "rs_pp": round(rs, 4), "window_value": s["window_value"]})
    if not ok:
        out["status"] = "NO_TRADE_NO_PASS"
        return out
    ok.sort(key=lambda r: (-r["rs_pp"], -r["window_value"], r["ticker"]))
    out["ranked"] = ok[:5]
    out["pick"] = ok[0]["ticker"]
    out["status"] = "PICKED"
    return out


def _filter(s: dict | None, idx: dict) -> str | None:
    need = ("market", "kind", "listed_sessions", "prev_close", "upper_limit",
            "p1450", "p1520", "day_value", "window_value")
    if s is None or any(s.get(k) is None for k in need):
        return "DATA_MISSING"
    if s["market"] not in INDEX_OF or s["kind"] != "COMMON":
        return "NOT_COMMON_KOSPI_KOSDAQ"
    ix = idx.get(INDEX_OF[s["market"]]) or {}
    if ix.get("p1450") is None or ix.get("p1520") is None:
        return "DATA_MISSING"
    if EXCLUDED_FLAGS & set(s.get("flags", [])):
        return "FLAGGED"
    if s["listed_sessions"] < MIN_LISTED_SESSIONS:
        return "NEW_LISTING"
    if s["p1520"] < MIN_PRICE:
        return "PRICE"
    if s["day_value"] < MIN_DAY_VALUE or s["window_value"] < MIN_WINDOW_VALUE:
        return "LIQUIDITY"
    if s["p1520"] >= s["upper_limit"]:
        return "UPPER_LIMIT_1520"
    if s["p1520"] <= s["prev_close"]:
        return "NOT_UP_ON_DAY"
    rs = _ret(s["p1450"], s["p1520"]) - _ret(ix["p1450"], ix["p1520"])
    if rs <= 0:
        return "RS_NOT_POSITIVE"
    return None


def settle(day: dict, decision: dict) -> dict:
    """D-0 종가 진입 → D+1 시가 청산. 체결 가정과 비용을 적용한다."""
    tk = decision.get("pick")
    if not tk:
        return {"status": decision["status"]}
    s = day["stocks"][tk]
    close, d1_open = s.get("close"), s.get("d1_open")
    auction_value = (s.get("close_auction_volume") or 0) * (close or 0)
    if close is None:
        return {"status": "PENDING_CLOSE", "ticker": tk}
    if close >= s["upper_limit"] or auction_value <= 0 or NOTIONAL > MAX_AUCTION_SHARE * auction_value:
        return {"status": "UNFILLED", "ticker": tk, "auction_value": auction_value}
    if s.get("d1_base") is not None and s["d1_base"] != close:
        return {"status": "EXCLUDED_BASE_ADJUSTED", "ticker": tk}
    if d1_open is None:
        return {"status": "PENDING_EXIT", "ticker": tk}
    gross = _ret(close, d1_open)
    ix = day["index"][INDEX_OF[s["market"]]]
    mkt = _ret(ix["close"], ix["d1_open"]) if ix.get("close") and ix.get("d1_open") else None
    return {
        "status": "SETTLED", "ticker": tk, "entry": close, "exit": d1_open,
        "exit_flag": s.get("d1_flag"),
        "gross_pct": round(gross, 4),
        "net_pct": round(gross - COST_PCT, 4),
        "excess_vs_index_pct": None if mkt is None else round(gross - mkt, 4),
        "grid": {f"c{c}_s{sl}": round(gross - c - sl, 4) for c in COST_GRID for sl in SLIP_GRID},
    }


def external(day: dict) -> list[dict]:
    rows = []
    for e in day.get("external", []):
        sent = e.get("sent_at") or ""
        if len(sent) < 19 or sent[:10].replace("-", "") != day["date"]:
            tier = "UNVERIFIED"
        elif sent[11:19] <= SIGNAL_HHMMSS:
            tier = "SAME_TIME"
        elif sent[11:19] < "15:30:00":
            tier = "IN_AUCTION"
        else:
            tier = "AFTER_CLOSE"
        s = day.get("stocks", {}).get(e["ticker"], {})
        gross = None
        if s.get("close") and s.get("d1_open"):
            gross = round(_ret(s["close"], s["d1_open"]), 4)
        rows.append({"ticker": e["ticker"], "tier": tier,
                     "accessible": tier in ("SAME_TIME", "IN_AUCTION"),
                     "gross_pct": gross,
                     "net_pct": None if gross is None else round(gross - COST_PCT, 4)})
    return rows
```

**구현 메모 (규칙 해석의 범위):**
- **KIND 분 단위 시각:** 이 코드는 `published_at`을 초 단위 문자열로 받는다. KIND 분 단위 시각은
  수집기가 `HH:MM:59`로 넣는다(§3.2). 합성 사례 `J010`의 15:20:00은 초 단위 소스를 가정한
  경계 시험이다.
- **`close_auction_volume`의 대체 계산과 플래그 붙이기:** 일봉 거래량 − 장중 봉 합계 같은
  §3.3의 대체 계산, 그리고 `D1_LATE_OPEN`, `HALT_EXIT` 같은 플래그 붙이기는 수집기 몫이다.
  이 함수는 채워진 값만 본다.
