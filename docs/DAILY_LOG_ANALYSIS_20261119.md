## 4. 10시 개장일에 봇이 한 일 — 다음 10시 개장일(연초 첫 거래일)의 근거

- **휴장 판정은 걸리지 않았다.** `paper_fast_probe`의 휴장 판정은 세 신호가 모두 맞아야 휴장으로 보는데(fail-open), 그렇게 되지
  않았다. `MARKET_CLOSED` 줄이 없다.
- **빠른 경로는 유효 호가 0으로 스스로 물러났고, 레거시 F1은 갭 0%만 보고 끝났다.** 주문은 나가지 않았다.
- **두 번째로 예상했던 경로(주문 → 첫 체결 대기 타임아웃 → 취소)는 시험되지 않았다.** 후보가 하나라도 갭 범위에 들었다면 장전
  동시호가(09:00 ~ 10:00)에 주문이 들어갔을 것이다. 취소가 실패하면 10:00에 체결될 수 있다는 위험은 이날 자료로 지울 수 없다.
- 개장 뒤(10:00 ~ 16:30) 봇은 아무것도 하지 않았다. 이날 장은 관측도 거래도 없이 지나갔다.
- **C1 종가 스크리닝**은 예약 작업 두 개를 전날 밤 꺼 두었고, 16:39에 손으로 돌렸다(대상 59, 후보 3, `degraded=false`).
  예약 작업은 16:42에 다시 켰다(다음 실행 11/20 15:20, 15:32).
- **백필**: 16:39 첫 실행이 호출 한도로 설계대로 멈췄고(종료 코드 2), 다시 돌려 끝냈다. 이날 쌍은 `20261119_460940` 330봉인데
  **10:00 ~ 15:30만 있다.** 백필이 09:00 ~ 15:30 기준으로 받기 때문에 15:30 ~ 16:30이 빠졌다. 10시 개장일 대응을 설계할 때 같이 다룬다.
